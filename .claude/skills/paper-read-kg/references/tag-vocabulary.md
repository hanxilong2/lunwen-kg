# Standardized Tag Vocabulary

All paper `tags` must be selected from this vocabulary. The vocabulary is
designed to be comprehensive across common academic domains — extensions
are rarely needed. If a genuinely uncovered concept appears, derive a tag
following the `snake_case` naming convention.

## Usage Rules

1. Select 3–5 tags per paper that best characterize its core methodology and domain.
2. Prefer existing tags over creating new ones. The vocabulary is deliberately broad.
3. When a paper spans domains, select tags from each relevant domain.
4. If a concept genuinely has no matching tag, derive one in `snake_case` following
   the naming pattern above (domain_concept, e.g., `agriculture_yield_prediction`).
